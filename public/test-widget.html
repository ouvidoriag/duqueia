⚡ O que é o Chat Widget Embutível?

● Pronto para Produção

O Chat Widget é uma solução leve (apenas 13 KB, em JavaScript puro sem frameworks) que adiciona um botão flutuante com o mascote oficial do Duque IA no canto da tela de qualquer site da Prefeitura. Ao clicar no mascote, abre-se uma janela de conversa rápida sem tirar o munícipe da página atual.

🚀 Instalação Rápida (1 Linha de Código)

Copie e cole este código antes da tag de fechamento </body> em qualquer site ou sistema web:

HTML (Sites externos, WordPress, Joomla, Portais) 
<script 
  src="https://ogm.duquedecaxias.rj.gov.br/duqueia/widget.js"
  data-title="Duque IA"
  data-position="bottom-right"
  data-theme="prefeitura"
  defer>
</script>
ℹ️
Carregamento sem atrasos: O script usa defer para garantir que a página principal carregue primeiro, sem impactar na velocidade do portal nem na nota de performance (Lighthouse/SEO).

⚙️ Parâmetros de Configuração (data-attributes)

Personalize o comportamento e a aparência adicionando atributos à tag <script>:

Atributo Padrão Valores Disponíveis Descrição
data-position bottom-right bottom-right, bottom-left Canto da tela onde o botão flutuante ficará fixado.
data-theme prefeitura prefeitura (Azul), verde (Saúde/Ambiente), escuro (Dark) Tema de cores da janela do chat.
data-title Duque IA Texto livre (Ex: "Atendimento Saúde", "Dúvidas IPTU") Título no topo da caixa de diálogo.
data-char boas_vindas boas_vindas, saude, atendimento, joinha, executivo Foto/mascote exibido no botão flutuante e no cabeçalho.
data-allowed-origins Origem do script Lista separada por vírgula de domínios autorizados Validação de segurança postMessage para evitar abusos.

Integrando no WordPress / CMS

Abra o arquivo footer.php do seu tema filho ou utilize o plugin "Insert Headers and Footers" e cole no bloco Footer:

WordPress footer.php
<?php wp_footer(); ?>
<script src="https://ogm.duquedecaxias.rj.gov.br/duqueia/widget.js" defer></script>
</body>

Integrando no React / Next.js

Adicione dinamicamente através de um useEffect ou utilize o componente next/script:

Next.js / React
import Script from 'next/script';

export default function Layout({ children }) {
  return (
    <>
      {children}
      <Script 
        src="https://ogm.duquedecaxias.rj.gov.br/duqueia/widget.js" 
        strategy="lazyOnload" 
      />
    </>
  );
}

🖥️ O que é a Página de Chat Completa?

● Modo Imersivo

A Página de Chat Completa é ideal para ser usada como canal principal de atendimento ao munícipe (ex: chat.duquedecaxias.rj.gov.br), para embutimento em tela cheia dentro de Aplicativos Móveis (Android / iOS via WebView), ou dentro de portais através de um <iframe> dedicado em uma página inteira de serviços.

🚀 Abrir Chat Oficial Completo (/chat.html) 🔍 Abrir Versão Embed Leve (/embed/chat)

📱 Embutir em Aplicativo React Native (Expo)

Utilize a biblioteca react-native-webview para criar uma tela nativa de atendimento:

ChatScreen.jsx (React Native) 
import React from 'react';
import { SafeAreaView, StyleSheet } from 'react-native';
import { WebView } from 'react-native-webview';

export default function ChatScreen() {
  return (
    <SafeAreaView style={styles.container}>
      <WebView
        source={{ uri: 'https://ogm.duquedecaxias.rj.gov.br/duqueia/embed/chat?theme=prefeitura' }}
        javaScriptEnabled={true}
        domStorageEnabled={true}
        startInLoadingState={true}
      />
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#ffffff' }
});

📱 Embutir em Aplicativo Flutter (Android / iOS)

Utilize o pacote oficial webview_flutter para adicionar o Duque IA no app:

chat_page.dart (Flutter) 
import 'package:flutter/material.dart';
import 'package:webview_flutter/webview_flutter.dart';

class DuqueChatPage extends StatefulWidget {
  @override
  _DuqueChatPageState createState() => _DuqueChatPageState();
}

class _DuqueChatPageState extends State<DuqueChatPage> {
  late final WebViewController controller;

  @override
  void initState() {
    super.initState();
    controller = WebViewController()
      ..setJavaScriptMode(JavaScriptMode.unrestricted)
      ..loadRequest(Uri.parse('https://ogm.duquedecaxias.rj.gov.br/duqueia/embed/chat'));
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Atendimento Duque IA'), backgroundColor: Color(0xFF004A99)),
      body: WebViewWidget(controller: controller),
    );
  }
}

Se o objetivo for disponibilizar o chat fixo ocupando uma página inteira de suporte do portal:

HTML iFrame Responsivo 
<!-- Container responsivo com altura total -->
<div style="width: 100%; height: 750px; max-width: 900px; margin: 0 auto; border-radius: 16px; overflow: hidden; box-shadow: 0 4px 20px rgba(0,0,0,0.1);">
  <iframe 
    src="https://ogm.duquedecaxias.rj.gov.br/duqueia/embed/chat?theme=prefeitura&title=Atendimento%20Cidad%C3%A3o"

    height="100%" 
    frameborder="0"
    allow="microphone"
    title="Duque IA">
  </iframe>
</div>

⚖️ Quando usar o Widget ou a Página Completa?

Critério Versão 1: Chat Widget Versão 2: Página Completa
Objetivo Principal Tirar dúvidas rápidas sem tirar o munícipe da página Atendimento aprofundado, abertura de protocolo e navegação guiada
Espaço Ocupado Discreto (canto inferior direito) Tela cheia (100% largura e altura)
Melhor Utilização Portal da Prefeitura, Notícias, IPTU Online, Carta de Serviços Aplicativos de celular (Android/iOS), Totens físicos, Página de Ouvidoria
Complexidade de Instalação Extremamente simples (1 tag de script) Link direto ou WebView nativa
