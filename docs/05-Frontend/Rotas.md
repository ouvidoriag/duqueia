# Rotas e Visualização do Frontend — Duque IA

O servidor Node.js expõe os arquivos estáticos de forma direta no navegador:

- `http://localhost:3001/` ou `/chat.html` -> Interface principal do Chatbot.
- `http://localhost:3001/dashboard.html` -> Painel de Telemetria e Monitoramento de Produção.
- `http://localhost:3001/arquitetura.html` -> Exibição técnica do RAG.
- `http://localhost:3001/prompts.html` -> Exposição de prompts da IA.
- `http://localhost:3001/organograma.html` -> Organograma do governo municipal.
