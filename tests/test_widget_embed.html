🧪 Teste de Integração do Widget

Esta página simula um portal externo da Prefeitura que incorpora a Duque IA via <script>.

O widget aparece no canto inferior direito. Clique no mascote para abrir o chat.

✅ Checklist de Verificação

Verifique manualmente os seguintes comportamentos:

  • 🔵 Mascote aparece no canto inferior direito
  • 🔵 Tooltip "Falar com a Duque IA" ao passar o mouse
  • 🔵 Clique no mascote → painel abre com animação
  • 🔵 Pressionar ESC → painel fecha
  • 🔵 Badge laranja aparece quando chega mensagem nova (painel fechado)
  • 🔵 Badge some ao abrir o painel
  • 🔵 Botão "expandir" no iframe → painel aumenta para tela cheia
  • 🔵 Botão "fechar" no iframe → painel fecha e foco retorna ao botão
  • 🔵 Eventos aparecem no painel de debug (botão abaixo)
  • 🔵 Em tela < 480px → painel ocupa largura total, bottom sheet

🏷️ Tags de configuração disponíveis

data-position data-theme data-title data-char data-src data-mascot-src data-allowed-origins data-z-index

📡 API JavaScript disponível

DuqueWidget.open()           // Abre o painel
DuqueWidget.close()          // Fecha o painel
DuqueWidget.toggle()         // Alterna aberto/fechado
DuqueWidget.send('texto')    // Envia mensagem ao chat
DuqueWidget.version          // Versão do widget

📡 Eventos postMessage recebidos
